STOCKIFY - INVENTORY MANAGEMENT SYSTEM
========================================
1. Extract this folder.
2. Open the Inventory-Management folder in VS Code.
3. Install/enable Live Server.
4. Right-click login.html -> Open with Live Server.
5. Demo login: admin@gmail.com / admin123.

Features:
- Dashboard and product CRUD
- Sales with multiple products, discounts, tax and payment balance
- Stock deduction and stock movement log
- Invoice display and print
- Sales returns, automatic stock restoration and refund records
- Customer history
- Inventory report and CSV export
- LocalStorage persistence

Data is stored in this browser's LocalStorage. This is a frontend demo, not a secure production accounting system.
